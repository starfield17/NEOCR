# ADR 0005: Git is the continuity source of truth

Status: accepted

The canonical remote is `https://github.com/starfield17/NEOCR.git`. Completed, verified increments are commits; active work uses a pushed feature branch. `docs/handoff/CURRENT.md` is the mutable handoff and the commit containing it defines its code baseline. No session relies on local chat history as the only record of an architectural choice.
